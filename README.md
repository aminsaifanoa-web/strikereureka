IslandChess is a tournament chess agent for AI Chessathon. It searches with iterative deepening negamax plus alpha-beta pruning, quiescence search, a transposition table, null-move pruning and late-move reduction, using a handcrafted tapered material and piece-square evaluation compiled with numba and wall-clock time management for the 120 second plus 0.5 second increment time control. It always returns a legal UCI move for the side to move, plays in a classical positional style, and every line of it was written specifically for this event.
